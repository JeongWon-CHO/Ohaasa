# 말투와 반응의 다양성

고정된 가짜 인물을 만드는 설정이 아니다. 나이·성별·직업·별자리로 성격을 배정하지 않는다. 기존 작성자 식별자나 프로필을 변경하는 자료로도 사용하지 않는다.

| 방향 | 답변의 특징 | 댓글에서 가능한 반응 |
| --- | --- | --- |
| 담백한 해요체 | 선택 하나를 짧게 말함 | 감상이나 구체적인 질문 |
| 편한 반말 | 설명 없이 떠오른 말을 던짐 | 부러움·만류·가벼운 참견 |
| 말이 적은 쪽 | 단어·숫자·대상만으로 끝냄 | 22·왜? 같은 짧은 반응 |
| 조금 망설이는 쪽 | 모름·아직·두 마음을 허용 | 결론이나 해결을 강요하지 않음 |
| 가벼운 장난 | 말장난·초성·비튼 말끝 | 의성어·연상·가벼운 놀림, 표적 괴롭힘은 제외 |
| 자기 이야기 | 같은 질문에 자기 선택을 말함 | 상대 답에서 자기 경험이나 걱정으로 화제를 옮김 |

배치별 필수 인원표가 아니다. 모든 글이 극단적으로 다른 말투를 가질 필요는 없다. 담백한 글 여러 개가 있어도 소재와 관점이 다르면 괜찮다.

## 배치 검토

- 모든 글의 시작이 '오늘은', 끝이 '~싶어요'인지 본다. 자연스러운 반복은 허용하되 같은 문장 틀이 전체를 지배하면 일부를 바꾼다.
- 소재뿐 아니라 태도도 본다. 모두가 들뜨거나, 피곤하거나, 작은 교훈을 얻고 있지는 않은지 확인한다.
- 모든 글을 두 문장으로 맞추거나 웃음 표시를 할당하지 않는다. 진지한 질문에서는 가벼운 농담이라는 방향보다 질문 맥락을 우선한다.
- 댓글이 전부 질문·공감·응원인지 본다. 초성 동의, 장난, 일상적인 참견, 연상과 자기 이야기도 가능하다. 모든 댓글을 완성 문장으로 고치거나 같은 조합을 기계적으로 순환시키지 않는다.
- 이전 답변이 주어졌으면 소재와 상황을 비교한다. 실제 이용자의 사연을 새 글의 재료로 복제하지 않는다.
